A token launch radar ranking 178 pre-token protocols by implied value — all 40 watchlist protocols covered, each with an 8-step farm plan — behind a sortable dark-console dashboard. The model is calibrated from the snapshot's own live-token protocols, so the values follow from the data, not a hardcoded list.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
